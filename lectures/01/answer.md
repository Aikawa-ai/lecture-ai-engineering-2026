## 宿題

- 取り組んだレベル：実装

- やったこと：
app/ask.py に --chat オプションを追加し、同じChatオブジェクトを使って、会話履歴を保ったまま続けて質問できるようにした。各回答の入力・出力トークン数を表示し、exit・quit・終了、または Ctrl+D で終了できるようにした。uv run python -m app.ask --chat を実行し、gemini-3.5-flash-lite と好きな色について会話した。

- 結果：
最初に「私の好きな色は青です。」と伝えると、モデルは青について説明し、「特にどのあたりの青が好きですか？」と質問した。このときのトークン数は入力7・出力64だった。
続けて「ターコイズです。」と伝えると、「先ほどは『青です』と教えていただきましたが、現在は『ターコイズ』が好きな色なんですね！」という内容の回答が返った。このときのトークン数は入力84・出力96だった。2回目の回答が最初の「青」という発言に触れており、会話履歴を踏まえた応答になっていることを確認できた。

- 気づき・疑問：
「ターコイズです。」という短い返答だけでも、モデルは好きな色の話の続きとして応答した。会話履歴を渡すことで、毎回話題を説明し直さずに会話を続けられると分かった。一方で、青の具体的な色合いを答えたつもりでも、モデルは「先ほどは青、現在はターコイズ」と好みが変わったように表現していた。履歴を参照できても、意図を必ず正確に理解するとは限らないと感じた。また、2回目の入力は短いのに、入力トークン数は7から84に増えた。過去の質問と回答も入力に含まれるため、長い会話では履歴をどこまで残すべきかを考えたい。
